# Flyrank Backend Engineer Internship

A collection of backend engineering projects completed during my Flyrank internship. Each project focuses on practical API development, authentication, database integration, documentation, and production-oriented backend workflows.

## Projects

| Weeks | Project | Highlights |
|---|---|---|
| Weeks 1 to 3 | [CRUD API](./CRUD-API) | Task-management REST API built with Node.js, Express, PostgreSQL, Docker, and Docker Compose |
| Week 4 | [Auth Login API](./Auth-Login) | Supabase authentication API with JWT-protected routes, reusable middleware, logout, and Swagger UI |

## What This Repository Covers

- RESTful API design with Node.js and Express
- PostgreSQL database integration and CRUD operations
- Dockerized local development environments
- Supabase Auth and JWT based route protection
- Reusable Express middleware
- Swagger and OpenAPI documentation
- Git and GitHub project workflows
